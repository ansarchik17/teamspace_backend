# Локальный документ задачи: Интеграция генерации презентаций 2slides с бюджетами

**Точка инвентаризации**: B17  
**Дата оформления**: 19 октября 2026 года  
**Статус**: Выделена самостоятельная задача с блокирующими условиями  

---

## 1. Затрагиваемые компоненты и файлы

- `internal/service/twoslides_service.go` — вызов внешнего HTTP API 2slides (`POST /api/v1/slides/generate`).
- `internal/handler/notebook_handler.go` — эндпоинт `GenerateSlidesWithTwoSlides` (`POST /notebook/slides/2slides/generate`).
- `internal/config/config.go` — секция `TwoSlidesConfig` (`TWOSLIDES_BASE_URL`, `TWOSLIDES_API_KEY`).
- `internal/domain/ai_credits.go` — добавление тарификации для нетокенных внешних провайдеров (job-based / slide-based).

---

## 2. Плательщик и атрибуция расходов

- Плательщик: Авторизованный пользователь Notebook (`userID` + `organizationID` из JWT контекста).
- Идентификатор операции: `twoslides:<operationID>:generate`.
- Подмена на сервисного плательщика запрещена.

---

## 3. Модель и контракт usage

- Провайдер: Внешний сервис 2slides.
- Характер услуги: **Нетокенная операция**. Провайдер возвращает JSON с `jobId` и ссылкой на готовую презентацию.
- Единица расхода: Задание (job) или слайд (slide-count). Токены провайдером не возвращаются.
- Контракт usage: **Не определён в рамках текущей токенной политики `credits-v1`**. Политика `credits-v1` строго требует целочисленных токенов (`InputTokens`, `OutputTokens`).

---

## 4. Необходимые изменения в кодовой базе

1. Внедрить в `internal/domain/ai_credits.go` поддержку тарификации дискретных заданий (`EndpointKind: "presentation_job"`, фиксированная стоимость в микрокредитах за 1 презентацию).
2. Разработать адаптер резервирования для нетокенных заданий (`TwoSlidesPaidCaller`).
3. В `TwoslidesService.Generate` перед вызовом внешнего HTTP API производить резервирование по фиксированной ставке, а при успешном старте задания — фиксацию списания (`settle`).

---

## 5. Зависимости и блокирующие условия

1. **Блокирующее условие №1**: Утверждение продуктового тарифа за генерацию 1 презентации 2slides в микрокредитах политики `credits-v1` (или новой версии `credits-v2`).
2. **Блокирующее условие №2**: Согласование семантики отмены и возврата кредитов, если внешнее асинхронное задание 2slides упало на стороне стороннего сервиса после успешного вызова `POST /generate`.

---

## 6. Критерии приёмки

- Запрос к 2slides не отправляется при исчерпании лимита бюджета компании или личной квоты пользователя.
- Фиксация списания в `ai_reservations` с указанием внешнего `jobId`.
- Обработка повторной доставки запроса без дублирования списания.
- Unit- и интеграционные тесты блокировки по квоте и списания.
