Отдельная админка для внешних администраторов

Панель работает через отдельный Keycloak client, использует только разрешенные external-admin endpoints и не открывает основной backend-админский контур.

Вход во внешнюю админку

Авторизация выполняется через выделенный Keycloak client. Только пользователи с ролью external_user_admin и корректным azp получат доступ к операциям управления пользователями.
