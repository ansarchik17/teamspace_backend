# Карточка задачи

Перед выкладкой применить миграцию `20260924000100_allow_unassigned_tasks.sql`:
она разрешает `NULL` в прежнем поле `tasks.assignee_id` для карточек без исполнителя.
Откат миграции требует предварительно назначить исполнителей всем таким карточкам.

Все запросы требуют авторизации. Создание и редактирование используют существующие
права доски (редактор или владелец); чтение — существующую проверку доступа.

- `POST /api/v1/kanban/tasks` — создать карточку, ответ `201` с задачей.
- `GET /api/v1/kanban/tasks/:id` — прочитать карточку.
- `PUT /api/v1/kanban/tasks/:id` — изменить переданные поля, ответ `200` с задачей.
- `DELETE /api/v1/kanban/tasks/:id` — удалить карточку.
- `GET /api/v1/kanban/tasks/:id/history` — история изменений.

Пример создания:

```json
{
  "board_id": "UUID доски",
  "title": "Подготовить отчёт",
  "description": "Собрать результаты за квартал",
  "assignee_ids": [12, 34],
  "priority": "high",
  "due_at": "2026-10-01T18:00:00+05:00",
  "original_estimate_sec": 7200
}
```

Обязательны `board_id` и непустой `title`. Пробелы по краям названия удаляются.
`created_by` — постановщик, автоматически берётся из авторизованного пользователя
при создании и не изменяется через карточку.

`priority`: `low`, `medium`, `high`, `critical`; при создании по умолчанию `medium`.
Переданный приоритет нормализуется (регистр и пробелы), неизвестный или пустой при
редактировании отклоняется. Исполнители необязательны; ID должны быть положительными,
дубликаты удаляются. Проверяются существование пользователей и доступ к ним по
действующим правилам организации. Поддерживается прежний `assignee_id`.

Описание и срок необязательны. `due_at` — RFC3339 с часовым поясом; некорректная
или нулевая дата отклоняется. Прошедший срок допускается для просроченных задач.
`original_estimate_sec` не может быть отрицательным.

При обновлении отсутствующее поле остаётся прежним. Очистка:

```json
{"description": null, "due_at": null, "assignee_ids": []}
```

Также поддерживаются `clear_description: true` и `clear_due_at: true`.
Одновременная установка и очистка одного поля — ошибка `400`.
`title`, `priority`, `original_estimate_sec`, `assignee_ids`, `assignee_id` не
принимают `null` при обновлении; чтобы не менять их, не передавайте поле.
Ошибки валидации возвращают `400` с `{"error":"описание ошибки"}`.
Изменение и очистка описания/срока, назначение и снятие исполнителей попадают в историю.
