# Kanban API: аватар пользователя в `members`

## Контекст

Сейчас при первой загрузке Kanban-доски мобильное приложение было вынуждено запрашивать весь глобальный список пользователей организации через `GET /users`, чтобы сопоставить `user_id` исполнителей с их именами и аватарами.

Для мобильных клиентов это слишком тяжело по производительности: передаётся большой объём лишних данных, которые не нужны для открытия конкретной доски.

Со стороны мобильного фронтенда оптимизация уже сделана:

- убран тяжёлый запрос `GET /users` при открытии доски;
- полные имена участников теперь берутся напрямую из `full_name` внутри массива `members` в ответе `GET /kanban/boards/{boardId}`.

Оставшаяся проблема: в `members` нет поля с аватаром пользователя, поэтому в UI сейчас отображаются только текстовые инициалы вместо реальных изображений.

## Что реализовано

В элемент `members` добавлено поле `avatar`.

Источник данных:

- `users.avatar_url`

Если у пользователя аватара нет, значение поля должно быть `null`.

## Где работает

- `GET /kanban/boards/{id}` в массиве `members`

## Текущая структура элемента `members`

```json
{
  "board_id": "some-board-uuid",
  "user_id": 135,
  "role": "owner",
  "joined_at": "2026-05-30T12:00:00Z",
  "team_role": "Разработчик",
  "full_name": "Тамерлан Картаев"
}
```

## Актуальная структура

```json
{
  "board_id": "some-board-uuid",
  "user_id": 135,
  "role": "owner",
  "joined_at": "2026-05-30T12:00:00Z",
  "team_role": "Разработчик",
  "full_name": "Тамерлан Картаев",
  "avatar": "/uploads/avatars/user_135.png"
}
```

Примечание:

- если у пользователя нет аватара, возвращать `"avatar": null`

## Результат для мобильного клиента

Теперь мобильное приложение получает из ответа доски всё необходимое для отображения участников:

- `user_id`
- `full_name`
- `avatar`

Без дополнительного запроса в `GET /users`.

## Польза от изменения

1. Убираем необходимость загружать весь список пользователей организации при открытии доски.
2. Существенно уменьшаем объём данных и ускоряем загрузку Kanban на мобильных устройствах.
3. На карточках задач и в верхней панели участников сразу будут отображаться реальные аватары пользователей.

## Ограничение текущей реализации

Сейчас изменение внесено именно в `GET /kanban/boards/{id}`.

`GET /kanban/boards` список `members` не возвращает, поэтому для него отдельная правка не потребовалась.
