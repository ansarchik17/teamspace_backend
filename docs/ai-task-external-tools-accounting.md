включая токены, отдельные единицы STT/TTS и ограниченные полномочия фоновых

состояние до реализации шлюза.

## 2. Текущее состояние в основном бэкенде Go

- В кодовой базе основного бэкенда (`workspace-backend`) маршруты с префиксом `/api/tools/...` **не зарегистрированы** и не обрабатываются (в `internal/server/router.go` они отсутствуют).
- Это либо отдельные внешние edge/микросервисы (проксируемые через Nginx/Ingress), либо устаревшие прототипы клиентского интерфейса.
- В основном бэкенде платных вызовов для этих точек нет.

## 4. Зависимости и блокирующие условия

1. **Блокирующее условие №1**: Предоставление исходников и инфраструктурной карты сервисов, обслуживающих маршруты `/api/tools/...`.
2. **Блокирующее условие №2**: Для STT (X03, X04): разработка доменной модели тарификации аудиозаписей (секунды звучания в микрокредитах). Запрещено подменять секунды аудио токенами текста без спецификации.
3. **Блокирующее условие №3**: Для потоковых ответов (X01): стандартизация финального события потока (SSE `data: [DONE]` с чанком `usage`) для фиксации фактического расхода.

---

## 5. Критерии приёмки

- Все внешние шлюзы `/api/tools/...` либо маршрутизируются через единый авторизованный шлюз с валидацией бюджетов, либо выводятся из эксплуатации на фронтенде.
- Отсутствует возможность совершения бесплатных генераций в обход платформы.
