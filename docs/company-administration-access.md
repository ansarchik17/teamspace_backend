# BAS-017 BE-01: административные права

Администратор платформы определяется текущей ролью `users.role`, равной
`domain.RoleSuperAdmin`. Email `admin@admin.kz` не является условием доступа.
Директор определяется назначением `organizations.owner_id`, а не названием
должности, разрешениями приложений или ролью, переданной клиентом.

Проверки читают актуальное состояние БД. Неактивная или удалённая учётная
запись не допускается даже при наличии ранее выданного JWT. Отказ возвращает
стандартную ошибку API `FORBIDDEN` (HTTP 403) с локализацией ru/kk.

На `/api/v1/platform/organizations/**` допускается только активный
администратор платформы. Проверки распространяются также на корпоративные
провайдеры входа. Директор не может выбрать другую компанию через эти API.

На `/api/v1/organizations/current/**` компания определяется сервером по
пользователю. Изменение структуры, назначений и настроек доступа разрешено
активному владельцу этой компании либо администратору платформы. Обычное
чтение структуры и списка сотрудников остаётся доступным сотрудникам
компании: эти endpoints используются вне административного кабинета.

Существующие проверки принадлежности объектов компании сохраняются.
`can_manage_structure` в ответе текущей компании отражает административное
право, но не заменяет серверную проверку при изменении данных.

Новая роль и миграция не требуются. Управление модулями, квотами, интеграциями
и аудит будут расширены следующими задачами BAS-017.
