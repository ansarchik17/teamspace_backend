# CNT-001 — Справочник сотрудников

Авторизованным сотрудникам доступен справочник своей активной компании.

## API

- `GET /api/v1/contacts?q=ан&unit_id=<UUID>&position=Разработчик&limit=50&offset=0`
- `GET /api/v1/contacts/filters`

Список: `{items: [], total, limit, offset}`. Карточка содержит id, full_name,
email, username, position, avatar_url, availability_status, unit_id, unit_name,
manager_id. Пустые необязательные поля могут отсутствовать. Сортировка по имени
без учёта регистра, затем id; total и страница вычисляются одним SQL-запросом.

Поиск `q` — буквальная подстрока имени, email или логина без учёта регистра,
включая кириллицу. Пробелы по краям удаляются, пустой запрос выдаёт всех.
Длина q до 200 символов; position до 255. `%` и `_` не являются wildcard.
Фильтры сочетаются через AND. `unit_id` означает ровно выбранное подразделение,
без дочерних узлов. Должность — точное совпадение без учёта регистра и крайних
пробелов. Limit 1–100 (по умолчанию 50); offset >= 0. Неверные параметры — 400.
Чужое или неизвестное подразделение даёт пустой результат.

Filters возвращает `units` (id, parent_unit_id, name, unit_type) всей активной
структуры компании и `positions` активных сотрудников: без пустых значений,
с объединением регистра и крайних пробелов. Иерархия определяется parent_unit_id.

Удалённые и неактивные сотрудники не отображаются. Архивные и чужие подразделения
не раскрываются; manager_id возвращается только для активного сотрудника той же
компании. Компания определяется сервером, параметр organization_id не принимается.
Без активной компании — 404. Keycloak ID и административные роли не выдаются.

Новых миграций и настроек нет. Используются users, teams, organizations.
Фронтенд приложения не менялся. Для поиска при вводе фронтенду следует отправлять
GET после debounce 200–300 мс и отменять предыдущий запрос, сбрасывая offset при
смене запроса/фильтров. Задержка поиска на production-объёме данных не измерена.

Проверка: `go test ./...`; с одноразовой PostgreSQL:
`TEST_MESSENGER_DATABASE_URL=... go test ./internal/repository -run TestContactsIntegration -v`.
