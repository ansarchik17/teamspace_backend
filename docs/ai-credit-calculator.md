# Расчёт ИИ-кредитов: задача 08

Реализация: `internal/domain/ai_credits.go`. Основание — утверждённая спецификация `workspace-front/docs/ai-credit-calculation-spec.md`.

`CalculateAICredits(key, usage)` — чистая функция без БД, сетевых вызовов и изменения бюджета. Результат содержит целые `Microcredits`, точный `ModelKey` и копию весов `Rates` для сохранения в журнале. `1 кредит = 1000000 микрокредитов`. Не округляет отдельные вызовы до кредита, не применяет минимальную стоимость запроса.

## Вход и политика

Ключ `(ProviderID, EndpointKind, ModelID, PolicyVersion)` сопоставляется строго, с учётом регистра, без неявных алиасов, trim или fallback. Политика `credits-v1` содержит все 15 согласованных сочетаний provider/endpoint/model: 12 моделей NITEC chat, прямой OpenAI gpt-4o, embeddings bge-m3 и rerank bge-reranker-v2-m3. Реестр не экспортирует изменяемую map: возвращённый value snapshot не меняет правила последующих расчётов.

`AICreditRatesForModel` позволяет получить снимок коэффициентов до вызова для будущего резервирования. Наличие записи не даёт разрешение вызвать модель и не подтверждает контракт провайдера. Активация embeddings/rerank по-прежнему требует отдельной проверки семантики usage. Динамические модели и новые версии по умолчанию запрещены для расчёта.

Вход `AICreditUsage` — **уже нормализованный и проверенный адаптером расход**. Status допускает только verified/derived. InputTokens/OutputTokens обязательны как указатели int64, чтобы NULL не превращался в 0. TotalTokens и cached/reasoning необязательны. Только total не разлагается предположением на input/output. Для input-only профиля адаптер передаёт подтверждённый input и явный output=0; положительный output отклоняется.

Подтверждённые input=0/output=0 с verified/derived дают 0. Сам калькулятор не может проверить, действительно ли пустой/непустой ответ провайдера допускает нулевой usage: это обязанность доверенного адаптера. Нельзя просто проставить verified существующему DTO с нулевыми значениями по умолчанию.

Дробные/строковые/переполняющие JSON значения не представлены типом int64 и должны отклоняться адаптером при декодировании без промежуточного float. Калькулятор не является JSON-парсером и не включает нетокенные услуги, отображение процентов или разбор сумм из формы.

## Формула и ошибки

Считается сумма `regular_input*w_input + cached*w_cached + regular_output*w_output + reasoning*w_reasoning`, где regular исключает соответствующее подмножество. Если детализации нет — весь input/output по базовому весу. В v1 cached/reasoning имеют те же веса, что input/output. Total проверяется, но не добавляется к цене.

Отрицательные категории, детали больше totals, несогласованный total и ненулевой output input-only модели отклоняются. Проверки суммы токенов, каждого произведения и суммы слагаемых выполняются **до** соответствующей арифметической операции. Переполнение не обрезается и не оборачивается в отрицательное число.

Различимые доменные ошибки (для `errors.Is`): UnknownPolicy, UnknownModel, UnknownUsage, InvalidUsage, Overflow с префиксом `ErrAICredit`. При ошибке возвращается пустой `AICreditCalculation`; его нулевое поле Microcredits не означает бесплатность. HTTP-отображение ошибок и ru/kk-сообщения добавятся при подключении API, в этой задаче пользовательских текстов нет.

## Проверки и границы задачи

`go test ./internal/domain -count=1` проверяет пакет домена целиком, включая все согласованные модели, примеры 5/10 кредитов, 0,004 кредита без округления, embeddings/rerank, подмножества, verified zero, missing/unknown usage, неизвестные ключи/версии, сохранность снимка и границы int64: отдельно переполнение произведения и суммы допустимых произведений. Тесты точной арифметики MaxInt64 используют внутренний helper с единичными весами; публичная v1-политика остаётся неизменной.

Расчёт пока не подключён к провайдерам, журналу или списанию. Новых зависимостей, миграций и настроек окружения не требуется; фронтенд не меняется. Commit, push и развёртывание не выполняются.

Проверено 16 октября 2026 года: `go test ./internal/domain -count=1` прошёл; новые Go-файлы отформатированы gofmt. Интеграция с реальными usage/провайдерами в эту проверку не входит.
