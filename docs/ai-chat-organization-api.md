# Разделы, организация чатов и архив

Все маршруты находятся под /api/v1/ai и требуют действующей сессии. Пользователь берётся только из серверного контекста авторизации. Чужие чаты и разделы не возвращаются в списках; попытки изменения возвращают 404. Составной внешний ключ дополнительно запрещает связать чат с разделом другого пользователя.

| Метод и путь | Поведение |
| --- | --- |
| GET /sections | Личные разделы: id, name, description, color, chat_count, updated_at. Счётчик включает только неархивные чаты. |
| POST /sections | Создать раздел: name (1–120 символов), description (до 2000), color (#RRGGBB). |
| PATCH /sections/:sectionId | Изменить переданные name, description, color. |
| DELETE /sections/:sectionId | Удалить раздел. Его чаты и сообщения сохраняются, section_id становится null. |
| POST /chats | Помимо title/model принимает необязательный section_id собственного раздела. |
| GET /chats | Неархивные чаты. include_archived=true добавляет архивные. Возвращает pinned, archived, archived_at, section_id, preview и last_message_at. |
| PATCH /chats/:id | Переименование (title до 200 символов), закрепление (pinned), архивирование/восстановление (archived), перенос (section_id). null удаляет чат из раздела; отсутствие поля сохраняет прежнее значение. |

Архивирование не удаляет сообщения или документы. Восстановление очищает archived_at. Повторное архивирование сохраняет первоначальное archived_at. Организация чатов не вызывает провайдера и не расходует ИИ-кредиты.

Изнутри открытого раздела кнопка «Новый чат» создаёт черновик. При первой отправке section_id передаётся в POST /chats, поэтому создание и привязка к разделу выполняются одной операцией на сервере. При ошибке сохраняется черновик.
